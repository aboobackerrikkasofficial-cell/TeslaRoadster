# Tesla Roadster — The Future of Performance

An immersive, high-performance static digital portfolio showcasing the engineering, aerodynamics, and powertrain of the next-generation Tesla Roadster.

## Highlights
- **Video Hero Showcase:** Autoplaying cinematic testing footage of the Roadster with minimal sound controls.
- **Performance Dynamics:** Clean editorial statistics featuring 0–60 mph acceleration in 1.9s, 250+ mph top speed, 620 mi range, and 10,000 Nm wheel torque.
- **Engineering & Aerodynamics:** Explores instant torque delivery, tri-motor AWD, active aerodynamic contours, and cold-gas composite propulsion systems.
- **Interactive Testing Film:** 5-stage validation sequence (Reveal, Launch, Thrust, Control, Performance).
- **Responsive Exhibition Gallery:** Fluid horizontal swipe and touch controls.

## Tech Stack
- HTML5 & CSS3
- Tailwind CSS
- Vanilla JavaScript (Performance count-up, touch/swipe handling, intersection observers)
- Fluid Responsive Design (Desktop, Tablet, Mobile)

## Getting Started
Simply open `index.html` in any modern web browser or serve via any static file server:
```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```
